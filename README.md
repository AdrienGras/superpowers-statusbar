# superpowers-statusbar

Mod Claude Code qui affiche la progression d'un run [superpowers](https://github.com/obra/superpowers) : phase en cours, tâche du plan, boucle d'implémentation et de revue.

Deux vues :

- **Bande au-dessus du prompt** : timeline résumée du run.
- **Pane latéral** : toutes les étapes (brainstorming, plan, exécution SDD ou directe avec les phases écriture et relecture, revue finale, systematic debugging) et la position réelle dans le run.

> Statut : étude de faisabilité en cours.
