# Text Helpers in Bash Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three string helpers (`slugify`, `truncate`, `word_count`) in a sourced bash library.

**Architecture:** One library, `src/text.sh`, with one function per helper; one test file, `test/text.bats`. Each task adds one helper and its tests.

**Tech Stack:** Bash 4+, bats.

**Spec:** `docs/superpowers/specs/2026-01-01-text-sh-design.md`

## Global Constraints

- No dependency beyond coreutils, `sed` and `tr`.
- Functions only, in `src/text.sh`; sourcing it runs nothing.
- Tests live in `test/text.bats` and run with `bats test/text.bats`.

## Review Focus

- Empty input: each helper prints its empty result (nothing or `0`) and returns 0.
- `truncate` at the boundary: a text of exactly `MAX` characters comes back unchanged.

### Task 1: slugify

**Files:**
- Modify: `src/text.sh`
- Test: `test/text.bats`

**Interfaces:**
- Consumes: nothing.
- Produces: `slugify TEXT`, a function of `src/text.sh` that prints the slug.

- [ ] **Step 1: Write the failing test**

Append to `test/text.bats`:

```bash
@test "slugify lowercases and joins words with dashes" {
  run slugify 'Hello, World!'
  [ "$output" = "hello-world" ]
  run slugify '  --a  b--  '
  [ "$output" = "a-b" ]
  run slugify ''
  [ "$output" = "" ]
}
```

- [ ] **Step 2: Run test to verify it fails**

Run: `bats test/text.bats --filter slugify`
Expected: FAIL, `slugify: command not found`.

- [ ] **Step 3: Implement `slugify TEXT` in `src/text.sh`**

Lowercase with `tr`, then one `sed -E` for the dash runs and the trimming.

- [ ] **Step 4: Run test to verify it passes**

Run: `bats test/text.bats`
Expected: PASS

- [ ] **Step 5: Commit**

```bash
git add src/text.sh test/text.bats
git commit -m "feat: slugify"
```
